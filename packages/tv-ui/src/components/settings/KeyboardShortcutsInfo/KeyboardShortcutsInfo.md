## General

| Keyboard sequence | Action |
| ----------------- | ------ |
| `?` | Show keyboard shortcuts |

## Playback

| Keyboard sequence | Action |
| ----------------- | ------ |
| `Space` | Play/pause player |
| `←` or `→` | Jump forwards/backward. The jump amount is dependant on the length of the video and it will try to align jumps with nearly by markers if there are any. |
| Hold down `←` or `→` | Play/rewind at 2x speed |
| Hold down `←` or `→` then tap `↑` or `↓` | Increase or decrease the play/rewind speed |
| `↓` or `↑` | Go to next/previous media |
| `l` | Toggle looping the scene |
| `m` | Mute/unmute |

## Scene/Marker Actions

Ratings set on a marker apply to the marker's scene.

| Keyboard sequence | Action |
| ----------------- | ------ |
| `r {1-5}` | Set star rating | <!-- rating-system: stars -->
| `r 0` | Unset star rating | <!-- rating-system: stars -->
| `r {0-9} {0-9}` | Set decimal rating (e.g. `r 36` for `3.6`, use `r 00` for `10.0`) | <!-- rating-system: decimal -->
| ``r ` `` | Unset decimal rating | <!-- rating-system: decimal -->
| `d` | Delete the current scene/marker (opens the confirmation dialog with Delete focused, so `Enter` confirms) |
| `e` | Edit scene/marker tags |
| `i` | Toggle scene info |

## Display

| Keyboard sequence | Action |
| ----------------- | ------ |
| `c` | Toggle CRT effect |
| `f` | Toggle fullscreen |
| `o` | Toggle forced landscape orientation |
| `p` | Toggle picture-in-picture |
| `s` | Toggle subtitles |
